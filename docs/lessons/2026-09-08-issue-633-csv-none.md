# CSV 속성 제외는 직렬화 전에 적용한다

`CsvPropertyMode.None`은 속성을 제외한다고 문서화했지만 공통 헤더 생성과 spool 준비가 속성을 그대로 전달했다. 기존 테스트도 예약 이름 충돌을 기대해 잘못된 동작을 고정했다.

회귀 테스트는 실제 exporter가 `id,label,name`을 출력하고 예약 속성 `id`가 충돌하는 실패를 확인했다. 속성 제외를 헤더·spool·값 인코딩에 적용하여 파일과 임시 저장 모두에서 제외한다.

향후 제외 옵션을 추가할 때 최종 출력뿐 아니라 중간 직렬화 데이터도 검사한다. 테스트의 기존 기대값이 문서 계약과 일치하는지 먼저 대조한다. 테스트 작성 중 exporter 생성자에 옵션을 전달한 컴파일 오류는 RED로 세지 않았고 실제 export overload로 고친 뒤 동작 실패를 확인했다.

검증 결과는 연결 PR의 최신 명령과 결과를 기준으로 한다. 이 파일 자체는 전체 backend 통과를 주장하지 않는다.

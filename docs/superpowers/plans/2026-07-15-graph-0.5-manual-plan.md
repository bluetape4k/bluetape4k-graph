# Graph 0.5 Manual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a repository-owned, bilingual, release-validated Graph 0.5 manual covering all 15 publishable modules, 12 examples, four benchmark evidence groups, and five audited dark diagrams.

**Architecture:** `docs/manual/` is the authoring source of truth. A manifest and Ruby contracts pin release `0.5.1` to commit `3e0fa7cb9e3bc70c2743aeebda2487f3e45e4907`, classify the 31 release projects, enforce English/Korean route parity, and expose deterministic SVG/PNG assets. The website later imports the merged source as a versioned `0.5` snapshot while preserving release provenance.

**Tech Stack:** Markdown/YAML/JSON, Ruby 3 standard library and Minitest, Gradle project inventory export, SVG, CairoSVG, Python diagram audits, Astro/Starlight website sync.

---

## File ownership map

- Publication contract owner: `docs/manual/manifest.yaml`, `docs/manual/generated/manifest.json`, `scripts/manual/*.rb`, root Gradle inventory task.
- Architecture/guides owner: `docs/manual/{en,ko}/{index.md,getting-started.md,architecture/**,backends/**,graph-io/**,frameworks/**,guides/**}`.
- Module owner: `docs/manual/{en,ko}/modules/*.md` for exactly 15 publishable modules.
- Learning owner: `docs/manual/{en,ko}/examples/*.md` and `docs/manual/{en,ko}/benchmarks/*.md`.
- Diagram/integration owner: `docs/manual/assets/**`, rendering/diagram validation scripts, final manifest/index integration, publication metadata.

No worker edits another owner's paths. The integration owner resolves navigation and manifest changes after all content lanes finish.

### 10k loop vs batch smoke

측정 방식: 각 backend별로 10,000 vertices와 cycle 형태의 10,000 edges를 생성했다. Edge 측정은 vertex 준비를
측정 구간 밖에서 수행하고, edge create 구간만 loop와 batch로 비교했다. 수치는 로컬 smoke 측정값이며 정밀 JMH
결과가 아니라 PR 검증용 회귀 근거다.

| Backend | Rows | Vertex loop | Vertex batch | Vertex speedup | Edge loop | Edge batch | Edge speedup | Notes |
|---------|-----:|------------:|-------------:|---------------:|----------:|-----------:|-------------:|-------|
| TinkerGraph | 10,000 | 239 ms | 145 ms | 1.6x | 342 ms | 385 ms | 0.9x | in-memory snapshot/endpoint precheck 비용 때문에 edge batch는 성능보다 all-or-fail 의미가 핵심 |
| Neo4j | 10,000 | 12,312 ms | 360 ms | 34.2x | 10,254 ms | 382 ms | 26.8x | native `UNWIND` batch path 효과 확인 |
| AGE | 10,000 | 5,689 ms | 120 ms | 47.4x | 94,806 ms | 3,231 ms | 29.3x | literal-row chunked SQL batch path 효과 확인 |
